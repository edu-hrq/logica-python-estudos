# CONTROLE DE GASTOS EM PYTHON

## Descrição:

Sistema de Controle de Gastos desenvolvido em Python, permitindo o registro, visualização e análise de despesas de forma simples e eficiente via terminal.

O projeto foca na prática de conceitos da linguagem, com ênfase em organização de código, validação de dados e estruturação de sistemas interativos.

## Funcionalidades:

- Cadastro de gastos com nome e valor
- Listagem de todos os gastos cadastrados
- Cálculo automático do total de despesas
- Limpeza completa do controle de gastos
- Validação de entradas (valores inválidos e negativos)
- Tratamento de valores no formato brasileiro (R$, vírgula, etc.)

## Como usar:

1. Execute o arquivo 'main.py'
2. Escolha uma opção no menu interativo
3. Insira os dados necessários
4. Visualize e gerencie seus gastos

## Tecnologias:

- Python 3

## Aprendizados:

- Estruturas condicionais (if/else)

- Funções e organização modular
- Validação e tratamento de dados inseridos
- Manipulação de strings
- Estrutura de dados (Listas e Dicionários)
