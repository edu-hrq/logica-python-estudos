# To-Do List (Lista de Tarefas)

Aplicação em terminal que permite gerenciar tarefas com persistência de dados em JSON.

#### Funcionalidades:

* Adicionar tarefas
* Listar tarefas
* Excluir todas as tarefas
* Salvamento automático em arquivo `.json`

---

## Habilidades praticadas

* Estrutura de funções
* Manipulação de listas
* Dicionários
* Tratamento de erros (`try/except`)
* Manipulação de arquivos com JSON
* Organização de código

## ▶️ Como executar

1. Clone o repositório:

git clone https://github.com/edu-hrq/logica-python-estudos.git

2. Acesse a pasta do projeto:

cd logica-python-estudos/projetos/to-do-list

3. Execute:

python main.py
